# 证据目录（evidence）

本目录存放**实现所依据的反编译证据**，对应 `RULES.md` 第二节「参考模组源代码的强制流程」。

## 命名规则

    <模组名>-<类名>-<方法名>.txt

## 文件内容必须包含

1. 来源：jar 完整名；若在 `META-INF/jarjar/` 内，写出嵌套路径
2. 类名：完整限定名
3. 命令：可复现该输出的 javap 命令
4. 原始输出：不得编辑，保留字节码

## 使用方式

- 代码注释引用本目录文件名
- 提交信息写 `evidence: docs/evidence/<文件名>`
- 发现实现与证据不符时，以证据为准，改实现
